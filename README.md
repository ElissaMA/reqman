# ReqMan 定检准备系统 V3.6.0

> 飞机定检全流程数字化管理 · 本地轻量 Web · 只读对接川航 AMRO

## 核心优势

- **全流程统一管控**：工卡、航材、工作清单、需求单、飞机信息一站式管理，告别分散表格与人工核对。
- **省时防错**：Excel 批量导入导出 + 自动格式校验；高危删除二次确认；操作日志全程留痕可追溯。
- **AMRO 只读对接**：飞机在册、工作包、工卡版本一键比对，自动生成《工卡改版清单》、自动归档作废工卡（全程审计，不写 AMRO）。
- **轻量易部署**：单进程 Web 服务，浏览器即用；数据双文件分层存储，备份/恢复一键完成。

## 功能一览

| 模块 | 能力 |
|------|------|
| 工卡管理 | 工卡增删改查、搜索筛选、工卡组分类、高危删除二次确认 |
| 工具 / 航材 | 统一维护定检工具与航材资源，增删改查 |
| 工作清单解析 | 点击 / 拖拽上传 Excel，自动校验格式并解析 |
| 需求单生成 | 基于模板自动生成标准化需求单，在线预览 + 下载 |
| 飞机信息 | 机型、机号等基础信息维护 |
| 操作日志 | 自动记录增删改，时间 + 行为可追溯 |
| 库存查询 | 上传需求单批量查川航 AMRO 昆明库存，回填并标红 / 标黄 |
| 提醒单 | 工卡 / 工卡组提醒字段管理，一键生成下载 |
| AMRO 同步 | 飞机同步 / 工作包导入匹配 / 工卡版本比对 + 作废工卡库 |

## 快速开始（本地）

```bash
pip install -e ".[dev]"        # 安装依赖
python src/reqman/app.py       # 或双击 start.bat
```

访问 http://127.0.0.1:5001

## 操作说明

### 工卡与工卡组

- 「工卡信息」新建 / 编辑 / 删除工卡，按专业、提醒类型、类型筛选；工卡组用于归类与批量匹配。
- 删除工卡需二次确认。

### 需求单生成

1. 「工作包」导入 Excel 工作清单（或解析工作清单）。
2. 打开预览页，核对表单信息、运行条件、工具 / 航材分区。
3. 点「确认生成并下载」，输出 `定检需求单（B-{机号} {描述}）{日期}.xlsx`。

### 库存查询（AMRO 昆明库存）

1. 打开「库存查询」页，查看登录状态。
2. 点「🛠 新建配置」下载配置包（ZIP），本机解压双击 `start_login.bat`（首次自动装环境）。
3. 按提示关闭已登录 AMRO 页面 → 浏览器登录（先收验证码再账号登录）→ 点「✅ 完成登录」。
4. 页面显示「登录有效」后，上传需求单 Excel → 开始查询。
5. 点「下载副本」保存 `{原名}_库存已填_{时间戳}.xlsx`（G 列回填库存，缺料标红、临界标黄）。

> 登录凭证临时缓存 2 小时；有效期内异地登录会被挤掉，需重登。

### 提醒单

- 在工卡 / 工卡组维护提醒字段（确认 / 无需提醒 / 提醒类型），列表筛选与重点高亮。
- 点「一键生成」下载提醒单 Excel；支持旧版 VBA 配置一键迁移。

### AMRO 数据同步（只读）

- **飞机数据同步**：拉取在册飞机信息，按机队 / 基地过滤。
- **工作包**：查询任务接收包 → 导入 → 匹配到工卡；导入仅入库不匹配，匹配在「重新匹配」或预览时写入。
- **工卡版本比对**：全量或逐包比对 AMRO 工卡版本，生成《工卡改版清单》（单格三行：工卡号 / 名称 / 标记，新增=红、改版=蓝、作废=黑）。
- **作废工卡库**：版本检查自动归档 AMRO 查无的工卡（独立存储、主库瘦身），可在「🗂 作废工卡」查看或彻底删除。

### 操作日志

所有增删改自动记录，倒序展示、可滚动，用于审计与追溯。

## 常见问题

- **Linux 中文乱码？** 安装中文字体 `fonts-wqy-zenhei`。
- **数据在哪？** 核心 `data/reqman_db.json`，运行时 `data/reqman_db_runtime.json`，作废工卡 `data/cancelled_cards.json`。
