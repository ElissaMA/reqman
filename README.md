# 定检需求单管理系统 V3.4.5

飞机定检工卡、航材、工作清单、需求单传统人工表格管理方式效率低、易出错、数据无追溯。为规范定检业务流程、实现办公数字化，搭建轻量化本地Web管理系统，完成全流程业务统一管控。

## 产品概述

- **目标**：实现飞机定检全业务数字化管理，覆盖工卡、航材、清单、需求单、飞机信息；支持Excel批量导入导出；双文件分层存储；操作日志自动留存；轻量化部署
- **用户**：定检业务操作人员、系统运维管理人员、研发测试人员
- **定位**：轻量化、本地化、高可用的飞机定检专用管理系统，PC端本地部署

## 功能模块

- **工卡管理**：工卡CRUD + 搜索筛选 + 工卡组分类管理，高危删除二次确认
- **工具/航材管理**：统一维护定检工具、航材资源数据，支持增删改查
- **Excel工作清单解析**：支持点击/拖拽上传，自动校验格式、解析数据、过滤无效字段
- **需求单生成**：基于Excel模板自动生成标准化定检需求单，支持在线预览+本地下载
- **飞机信息管理**：维护机型、飞机编号等基础信息，支持增删改查
- **操作日志**：自动记录所有增删改操作，留存时间与行为记录，全程可追溯
- **库存查询**：上传需求单 Excel 批量查询川航 AMRO 昆明库存，副本回填 G 列并标红/标黄；登录脚本（scripts/）一键登录并自动上传凭证，登录状态可探活
- **提醒单**：工卡/工卡组提醒字段管理（确认/无需提醒/提醒类型），列表筛选与重点高亮，一键生成并下载提醒单 Excel；支持旧版 VBA 配置一键迁移

## 库存查询

### 使用流程

① 打开「库存查询」页 → 查看登录状态（未登录时提示新建配置）
② 点击「🛠 新建配置」下载配置包（ZIP，含 start_login.bat + amro_login.py + 说明）
③ 解压后双击 start_login.bat（首次自动安装运行环境，国内高速源）
④ 双击后按脚本内提示关闭已登录的川航 AMRO 页面并确认 → 浏览器弹出登录 → 登录后自动上传凭证，浏览器自动关闭
⑤ 页面状态变为"登录有效"（页面进入/切回自动探活，10 分钟轮询，过期提示重登）
⑥ 上传需求单 Excel → 开始查询 → 显示统计（成功/失败/标红/标黄）
⑦ 点击「下载副本」保存结果（暂存 output/，上传新需求单自动清除）

### 输出文件

- 文件名：`{原文件名}_库存已填_{时间戳}.xlsx`（保留原名）
- G 列回填昆明库存；库存<需求标红；需求≤库存<需求+2 标黄

### 登录说明

- 登录凭证一次性、临时缓存 2 小时（`AMRO_SESSION_TTL` 可调）
- 登录脚本环境存脚本同级 `.runtime/` 目录，仅首次安装下载
- 登录有效期内若在其他浏览器/设备登录 AMRO，当前登录将被挤掉，需重新运行脚本

## 需求单预览与输出

### 预览页面UI

页面按功能区域分为6个card区块：

- **① 表单信息**：机号、机型、日期、定检描述（可编辑）
- **② 运行条件**：项目/需求/备注/负责/MCC反馈（下拉+输入）
- **⑤ 新工卡**：未匹配/未完善工卡列表，支持编辑/新增，localStorage追踪处理状态
- **③ 工具区预览**：按专业分组（发动机/机体/电子），自动匹配，只读
- **④ 航材区预览**：同工具区结构，按专业分组
- **⑦ 备用工具航材**：按专业分组，每类最少2行

底部"确认生成并下载"按钮（二次确认弹窗）。

### 输出Excel格式

文件名：`定检需求单（B-{机号} {描述}）{日期}.xlsx`

**Sheet "需求单" 结构：**

| 行范围 | 区域 | 说明 |
|--------|------|------|
| 1-3 | 表头 | 标题+日期+机型信息 |
| 4-12 | 运行条件 | 项目/需求/备注/负责/MCC反馈 |
| 15起 | 工具区 | 按发动机→机体→电子分组，每类最少3行 |
| 工具区后 | 新工卡 | 红色字体标注未匹配/子工卡 |
| 新工卡后 | 航材区 | 同工具区结构 |
| 航材后 | 备用航材 | 按专业分组，每类最少2行 |

**9列定义：**

| 列 | 工具区 | 航材区 | 备用航材 |
|----|--------|--------|----------|
| A | 定检专业（工具） | 定检专业（航材） | 专业 |
| B | 设备名称 | 航材名称 | 航材名称 |
| C | 件号 | 件号 | 件号 |
| D | 工作名称 | 工作名称 | 工作名称 |
| E | 数量 | 数量 | 数量 |
| F | 备注 | 备注 | 备注 |
| G | 库存情况 | 库存情况 | 库存情况 |
| H | 区域放行 | 区域放行 | 调配数量 |
| I | 工具房确认 | MCC调配反馈 | MCC调配反馈 |

## UI视觉与交互规范

### 整体视觉调性
办公后台简约专业风格，低干扰、高实用性，无花哨动效，适配工业定检严谨业务场景。

### 基础视觉规范
- 主色调：浅科技蓝（按钮、选中、高亮）；辅助色：深浅灰
- 文字层级：标题加粗加深、正文标准色、备注浅灰色弱化
- 布局规范：统一卡片式布局，留白均匀、控件对齐规整
- 视觉要求：低饱和、高对比，保证数据清晰可读

### 通用交互规则
- 可点击元素hover变色反馈
- 删除等高危操作强制二次确认
- 操作完成后展示成功/失败提示
- 数据加载过程展示加载状态
- 空数据页面展示友好空状态

### 专项交互规则
- 列表筛选实时生效、支持重置清空
- Excel点击+拖拽双模式上传、格式前置校验
- 需求单支持独立页面预览，确认后生成下载
- 日志列表倒序展示、滚动加载

### 适配规范
适配PC主流分辨率，页面自适应缩放，表单、表格、按钮布局稳定。
